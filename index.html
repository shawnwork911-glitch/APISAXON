Manual / scheduled extraction

How this works Pick a company, its stations, a data resolution and a date range, then queue the extraction. Calls are paced to each brand's daily quota and resumable — if a run stops partway (quota reached, tab closed), the next run continues from where it left off. Results are appended to the Readings tab of your Google Sheet, and can also be downloaded as a standalone Excel file per run.

Jobs

Hourly vs Monthly

Sums Hourly-resolution readings into monthly totals per facility_id (grouped exactly like the Extraction tab's export settings) and compares them against Monthly-resolution readings already in your Google Sheet's Readings tab, flagging any month where they disagree by 0.005 kWh or more. Needs both Hourly and Monthly data already extracted for the same company.

Results

CORS proxy

Why this is needed Inverter-brand APIs are called server-to-server in your Postman collections; most block direct requests from a browser. Deploy the Azure Function or Cloudflare Worker template in /api-proxy (see its README), then paste its base URL below.

Google Sheets

One-time setup Create a Google Sheet with two tabs — Connections and Readings — share it with your service account's email as Editor, then paste the sheet's ID below (the long string in its URL between /d/ and /edit). No sign-in needed here — the proxy holds the service account credential. See docs/SETUP.md for the full walkthrough.

Daily automation (GitHub Actions)

This page can only run while it's open in a browser tab. For true unattended daily/hourly extraction, use the scheduled GitHub Action in /.github/workflows/daily-extraction.yml — it reads the same Google Sheet's Connections tab and writes to the same Readings tab, using its own copy of the service account credential (set as GitHub secrets). See docs/SETUP.md.
