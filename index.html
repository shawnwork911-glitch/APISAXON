Connected Inverter Brands

Manual / scheduled extraction

How this works Pick a company, its stations, a data resolution and a date range, then queue the extraction. Calls are paced to each brand's daily quota and resumable — if a run stops partway (quota reached, tab closed), the next run continues from where it left off. Results are appended to SolarExtractionData.xlsx in your SharePoint site, and can also be downloaded as a standalone Excel file per run.

Jobs

CORS proxy

Why this is needed Inverter-brand APIs are called server-to-server in your Postman collections; most block direct requests from a browser. Deploy the Azure Function or Cloudflare Worker template in /api-proxy (see its README), then paste its base URL below.

Microsoft 365 / SharePoint

One-time setup Register an Azure AD app (Single-page application, no client secret needed) with delegated Graph permissions Sites.ReadWrite.All and Files.ReadWrite.All, add this page's URL as a redirect URI, then fill in the IDs below. See docs/SETUP.md for the full walkthrough.
The extraction workbook (SolarExtractionData.xlsx) is saved into this library/folder. The SolarConnections list is always at the site level, regardless of this setting.

Daily automation (GitHub Actions)

This page can only run while it's open in a browser tab. For true unattended daily/hourly extraction, use the scheduled GitHub Action in /.github/workflows/daily-extraction.yml — it reads the same SharePoint connections list and writes to the same workbook. See docs/SETUP.md.
